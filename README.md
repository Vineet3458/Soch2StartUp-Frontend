# Soch2Startup – Frontend (React + Vite)

```bash
npm install
npm run dev      # http://localhost:5173  (proxies /api to the backend on :5000)
npm run build    # production build in dist/
npm test         # navigation and component unit tests
npm run lint     # ESLint code quality check (0 warnings, 0 errors)
```
